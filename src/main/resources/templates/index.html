Reel Tiles Count ChancesiPer-reel probability distribution for the number of visible tiles per reel. Each row is 6 comma-separated percentage values corresponding to tile counts 2, 3, 4, 5, 6, 7 — i.e. the 1st value is the chance a reel shows 2 tiles, the 2nd is for 3 tiles, …, the 6th is for 7 tiles. Values must sum to 100. Leave a row blank to use a uniform distribution.

Generate — Configuration Fields
Strategy Determines the algorithm used to place tiles on each reel strip.

SHUFFLE — Stochastic placement algorithm. Behaviour depends on whether restrictions are defined:
  With restrictions: For each position on the reel, a stack height is sampled from the weighted distribution defined by stackSizes / stackChances. A symbol is then chosen at random from the remaining tile pool and placed as a consecutive run of that height. Before committing the placement, the algorithm checks that the chosen symbol does not violate the minDistance constraint — i.e. the same symbol must not have appeared within the last N positions. If the constraint is violated, a different symbol is tried. If no valid symbol can be placed after exhausting all candidates, the attempt is abandoned and the entire reel is regenerated from scratch (up to 8 retries). If all retries fail, the reel is emitted as [].
  Without restrictions: All tiles are expanded into a flat list and shuffled uniformly at random (Fisher-Yates shuffle). Every tile is placed individually (stack size 1 for all). No distance constraints are applied.

FLAT — Deterministic sequential placement. All copies of symbol 1 are placed first, then all of symbol 2, and so on in ascending symbol order. No randomisation, no stacking, restrictions are ignored.
History size Maximum number of past generation results retained on disk. Allowed values: 1, 3, 5, 10, 20. When the limit is reduced, the oldest entries beyond the new limit are deleted immediately. Each entry is stored as a JSON file under ./history/.
Reel Set A named logical group of reel strips sharing one restriction configuration. The output JSON array contains one object per reel set with a setName and a reelSet array. Multiple reel sets can be configured to generate different volatility profiles or game modes in a single run.
Reels (Tiles Count) — R1, R2… Each row represents one reel strip. Enter a comma-separated list of non-negative integers where the Nth value is the count of symbol N on that reel. For example, 8, 34, 44, 18 defines a reel containing 8 copies of symbol 1, 34 of symbol 2, 44 of symbol 3, and 18 of symbol 4. The sum of all values is the total reel length.
Restrictions Define the stacking behaviour for reels within a reel set. Restrictions are applied cyclically by reel index: restriction 1 governs R1, restriction 2 governs R2, restriction 1 governs R3 again, and so on. The badge on each restriction header shows exactly which reels it governs. A reel set with no restrictions produces flat (sequential) output regardless of the selected strategy.
stackSizes Comma-separated list of allowed stack heights. A stack is a consecutive run of the same symbol. For example, 1, 2, 3 allows individual tiles, pairs, and triples. All values must be positive integers.
stackChances Relative weights controlling how often each stack height in stackSizes is selected. The values do not need to sum to any particular number — only their ratios matter. For example, with stackSizes: 1, 2, 3 and stackChances: 60, 30, 10, a height of 1 is chosen approximately 60% of the time. Must have the same length as stackSizes.
minDistance Minimum number of intervening symbols required between two stacks of the same symbol. A value of 1 means no two stacks of the same symbol may be adjacent. A value of 3 requires at least 3 different symbols between them. If this constraint cannot be satisfied after 8 placement attempts, the reel is emitted as [].
Generate — Controls
▶ Run Validates the current configuration, submits it to the backend via POST /api/generate, and writes the resulting JSON reel array to the Result pane. The result is also saved to the history.
Import (↓ button) Opens a dialog to paste the output of a COUNT conversion. The imported data populates the reel sets with the given tile counts. All existing reel sets are replaced. No restrictions are added — configure them manually before running.
+ Add reel set Appends a new reel set card pre-filled with default tile counts and one default restriction.
+ Add reel Appends a new reel row to the reel set. The cyclic restriction mapping recalculates automatically and all restriction badges update to reflect the new reel count.
+ Add restriction Adds a restriction entry to the reel set. Adding more restrictions than there are reels is blocked — additional restrictions would be unreachable due to cyclic mapping.
History panel Displays past generation results in reverse chronological order. Clicking an entry restores its output to the Result pane. The Clear history button deletes all history files from disk.
Convert — Fields & Controls
Format Output format for the conversion. The input is auto-detected regardless of which format is selected.
COUNT — Reconstructs the per-symbol tile counts from the reel strips (inverse of generation). The output is a JSON array of objects with setName and reelSetTileCounts fields. This output can be pasted directly into the Generate tab via the Import button.
JSON_ARRAY — Reformats the reel data as a JSON array of { setName, reelSet } objects, one entry per reel set. Each reelSet is an array of reel strips represented as integer arrays.
CSV — Emits one row per tile position across all reel strips. Columns: setName, reelIndex (0-based), position (0-based), gameIdTile. Requires the gameId field.
gameId Visible only when Format is CSV. A numeric game identifier that is prepended to the 3-digit zero-padded symbol index to form the gameIdTile column value. For example, gameId = 123 and symbol 1 produce 123001; symbol 42 produces 123042.
Input pane The input format is auto-detected on Run. Two formats are accepted:
JSON array — [{"setName":"…","reelSet":[[…],…]}]. This is the direct output of the Generate tab or a prior JSON_ARRAY conversion.
CSV — The output of a prior CSV conversion. Each row has the form "setName","reelIndex","position","gameIdTile". The symbol index is recovered from the last 3 digits of the gameIdTile value.
